# lp_select

## для локальной разработки и билда статичного сайта нужно:

- поставить Node.js (lts) https://nodejs.org/en
- в терминале перейти в корнь проекта 
- поставить зависимости `npm сi`
- для старта локального девсервера выполнить `npm run dev`
- в браузере открыть (localhost:3000/index3d.html)[http://localhost:3000/index3d.html]
